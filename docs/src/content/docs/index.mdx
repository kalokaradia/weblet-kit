`weblet-kit` is a small collection of typed helpers for arrays, objects, text, dates, numbers, functions, and common validation tasks. Import only the functions you need from one package entry point.

## Quick start

Install the package, then import the functions your code uses:

```sh
npm install weblet-kit
```

```ts
import { chunkArray, debounce, isEmail } from 'weblet-kit';

const pages = chunkArray(['a', 'b', 'c'], 2);
const valid = isEmail('dev@example.com');
const saveLater = debounce(() => console.log('saved'), 250);
```

Continue with [installation and imports](/getting-started/) or go directly to the [API reference](/api/).
